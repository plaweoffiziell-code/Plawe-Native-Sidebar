# Plawe Native Sidebar

Eine mobile-first Obsidian-Erweiterung, die die linke Seitenleiste ruhiger, klarer und iOS-nativer wirken lässt.

## Was sich verändert

- große, gut treffbare Touch-Flächen auf iPhone und iPad
- ruhiger Graphit-/OLED-Look mit dezentem Lavendel-Akzent
- klar erkennbare aktive Notiz und dezenter aktiver Ordnerpfad
- iOS-artiger großer Titel mit Vault-Name und aktuellem Ordner
- Schnellaktionen für Suche und neue Notiz
- komfortable und kompakte Ansicht
- funktioniert auch auf dem Mac und kann auf Wunsch nur mobil aktiviert werden

Das Plugin liest keine Notizinhalte und verändert bestehende Notizen nicht automatisch. Nur die ausdrücklich betätigte Schnellaktion **Neue Notiz** legt eine leere Notiz an. Es verwendet kein Netzwerk, keine Analyse-Dienste und keine Telemetrie.

## Installation mit BRAT

1. BRAT in Obsidian öffnen.
2. Den Befehl **BRAT: Add a beta plugin for testing** ausführen.
3. Als Repository eintragen:

   `plaweoffiziell-code/Plawe-Native-Sidebar`

4. **Plawe Native Sidebar** unter **Einstellungen → Community-Erweiterungen** aktivieren.

## Bedienung

Alle Optionen liegen unter **Einstellungen → Plawe Native Sidebar**. Zusätzlich gibt es drei Befehle:

- Native Sidebar ein-/ausschalten
- zwischen komfortabler und kompakter Ansicht wechseln
- aktuelle Notiz in der Seitenleiste zentrieren

## Kompatibilität

- Obsidian 1.7.2 oder neuer
- iPhone und iPad werden ausdrücklich unterstützt
- keine Desktop-only APIs und keine Node.js-Abhängigkeiten
